# HR Employee Attrition Dashboard | Power BI

## Project Overview
An interactive HR analytics dashboard built using Power BI to analyze employee attrition and identify patterns related to job satisfaction, experience, gender, job role, work-life balance, and overtime.

## Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

## Key Features
- Employee count, attrition count, and attrition rate KPIs
- Interactive charts for employee attrition analysis
- Slicers for department, job role, job involvement, and overtime
- Data-driven insights to support HR decision-making

## Dataset
The project uses four files: `Fact_Attrition.csv`, `Dim_Employee.csv`, `Dim_Department.csv`, and `Dim_Date.csv`.

## Objective
To explore employee attrition patterns and support data-driven workforce planning.
